AgentBay Deep Dive: OSS, Context, and Session Lifecycle

agentbay-guide

AgentBay Comprehensive Guide

AgentBay is Alibaba Cloud's sandbox environment service that provides AI agents with isolated cloud containers for executing code, running commands, and interacting with browsers. Think of it as "disposable cloud computers on demand."

This guide covers the internals: OSS, Context, File Sync, and Session Lifecycle.

  2. Context
  3. Mounting / File Sync

1. OSS (Object Storage Service)

What is OSS?

OSS (Object Storage Service) is Alibaba Cloud's distributed object storage system. In AgentBay, OSS serves as the persistent storage layer that bridges:

  • Your local machine
  • The ephemeral cloud session containers
  • Long-term persistent contexts
+----------------+       +-------+       +------------------+
|  Local Machine | <---> |  OSS  | <---> | Session Container|
+----------------+       +-------+       +------------------+
                             ^
                             |
                      +------+------+
                      |   Context   |
                      | (Persistent)|
                      +-------------+

How OSS Works Technically

OSS operates on a bucket/object model:

  • Bucket: A container for objects (like a root folder)
  • Object: A file stored in a bucket, identified by a key (path)

AgentBay uses pre-signed URLs for secure, temporary access:

  1. Client requests a pre-signed URL from AgentBay API
  2. AgentBay generates a time-limited URL with embedded credentials
  3. Client uploads/downloads directly to/from OSS using the URL
  4. URL expires after a set time (typically 1 hour)

How AgentBay Uses OSS Under the Hood

AgentBay abstracts OSS into two layers:

Layer 1: Direct OSS Operations (via session.oss)

# Initialize OSS environment with STS credentials
session.oss.env_init(
    access_key_id="your_sts_access_key_id",
    access_key_secret="your_sts_access_key_secret",
    security_token="your_sts_security_token"
)

# Upload from session container to OSS
session.oss.upload(bucket="my-bucket", object="data/file.txt", path="/tmp/file.txt")

# Download from OSS to session container
session.oss.download(bucket="my-bucket", object="data/file.txt", path="/tmp/file.txt")

# Anonymous upload/download (for public URLs)
session.oss.upload_anonymous(url="https://example.com/upload", path="/tmp/file.txt")
session.oss.download_anonymous(url="https://example.com/file.txt", path="/tmp/file.txt")

Layer 2: Context-Based Storage (via agent_bay.context)

Contexts use OSS internally but provide a higher-level abstraction:

# Get pre-signed upload URL for a context file
url_result = agent_bay.context.get_file_upload_url(context_id, "/path/to/file.txt")
# Returns: FileUrlResult with url and expire_time

# Get pre-signed download URL
url_result = agent_bay.context.get_file_download_url(context_id, "/path/to/file.txt")

OSS Pricing Model

OSS pricing is based on:

Component Price (China Regions)
Storage ~0.12 CNY/GB/month
PUT/COPY/POST requests ~0.01 CNY per 10,000 requests
GET requests ~0.01 CNY per 10,000 requests
Data transfer (outbound) ~0.50 CNY/GB

AgentBay bundles OSS costs into its pricing, so you typically don't pay OSS separately.

2. Context

What is a Context?

A Context is AgentBay's abstraction for persistent storage that survives session termination. While sessions are ephemeral (everything is lost when deleted), contexts persist.

Session 1 (ephemeral)     Session 2 (ephemeral)     Session 3 (ephemeral)
      |                         |                         |
      v                         v                         v
+-----+-------------------------+-------------------------+-----+
|                         Context (persistent)                  |
|                    (stored in OSS under the hood)             |
+---------------------------------------------------------------+

Context vs Session

Aspect Session Context
Lifetime Ephemeral (deleted on cleanup) Persistent (survives sessions)
Storage Container filesystem OSS-backed storage
Billing Per-second while running Per-GB stored + retention policy
Use case Compute environment Data persistence

How Context Relates to OSS

Contexts are stored in OSS buckets managed by AgentBay:

OSS Bucket (AgentBay-managed)
├── context-{context_id}/
│   ├── file1.txt
│   ├── dir/
│   │   └── file2.txt
│   └── ...

When you mount a context to a session, AgentBay:
1. Downloads context files from OSS to the session container
2. Monitors for changes during the session
3. Uploads modified files back to OSS when session ends

Context Lifecycle and Retention Policies

Contexts support configurable retention via RecyclePolicy:

from agentbay.context_sync import RecyclePolicy, Lifecycle

# Available lifecycle options
Lifecycle.LIFECYCLE_1DAY      # Keep for 1 day
Lifecycle.LIFECYCLE_3DAYS     # Keep for 3 days
Lifecycle.LIFECYCLE_5DAYS     # Keep for 5 days
Lifecycle.LIFECYCLE_10DAYS    # Keep for 10 days
Lifecycle.LIFECYCLE_15DAYS    # Keep for 15 days
Lifecycle.LIFECYCLE_30DAYS    # Keep for 30 days
Lifecycle.LIFECYCLE_90DAYS    # Keep for 90 days
Lifecycle.LIFECYCLE_180DAYS   # Keep for 180 days
Lifecycle.LIFECYCLE_360DAYS   # Keep for 360 days
Lifecycle.LIFECYCLE_FOREVER   # Keep permanently (default)

Context States

Contexts can be in the following states:

State Description
available Ready for use
in-use Currently mounted to a session
pre-available Being prepared
clearing Data is being cleared

Creating, Listing, Deleting Contexts

Create a Context:

from agentbay import AgentBay

agent_bay = AgentBay(api_key="your_api_key")

# Create a new context (or get existing one with same name)
result = agent_bay.context.get(name="my-project-data", create=True)
if result.success:
    context = result.context
    print(f"Context ID: {context.id}")
    print(f"Context Name: {context.name}")
    print(f"Created At: {context.created_at}")

List All Contexts:

from agentbay.context import ContextListParams

# List with pagination
params = ContextListParams(max_results=20)
result = agent_bay.context.list(params)

if result.success:
    for ctx in result.contexts:
        print(f"ID: {ctx.id}, Name: {ctx.name}")

    # Get next page if available
    if result.next_token:
        params.next_token = result.next_token
        next_result = agent_bay.context.list(params)

Get Context by ID or Name:

# By name
result = agent_bay.context.get(name="my-context")

# By ID
result = agent_bay.context.get(context_id="ctx-04bdwfj7u22a1s30g")

Update Context Name:

result = agent_bay.context.get(name="old-name")
if result.success:
    result.context.name = "new-name"
    update_result = agent_bay.context.update(result.context)

Delete a Context:

result = agent_bay.context.get(name="my-context")
if result.success:
    delete_result = agent_bay.context.delete(result.context)
    print(f"Deleted: {delete_result.success}")

Clear Context Data (without deleting the context):

# Synchronous clear (waits for completion)
clear_result = agent_bay.context.clear(context_id, timeout=60)

# Asynchronous clear (returns immediately)
clear_result = agent_bay.context.clear_async(context_id)

# Check clear status
status_result = agent_bay.context.get_clear_status(context_id)
print(f"Status: {status_result.status}")  # "clearing" or "available"

List Files in a Context:

files_result = agent_bay.context.list_files(
    context_id="ctx-xxx",
    parent_folder_path="/",
    page_number=1,
    page_size=50
)

for entry in files_result.entries:
    print(f"{entry.file_name} ({entry.file_type}) - {entry.size} bytes")

3. Mounting / File Sync

How ContextSync Works

ContextSync defines how a context is mounted to a session:

from agentbay.context_sync import ContextSync, SyncPolicy

# Basic mount
context_sync = ContextSync(
    context_id="ctx-xxx",
    path="/workspace"  # Mount point in session container
)

# Mount with custom policy
context_sync = ContextSync(
    context_id="ctx-xxx",
    path="/workspace",
    policy=SyncPolicy.default()
)

SyncPolicy Options

SyncPolicy controls upload, download, and lifecycle behavior:

from agentbay.context_sync import (
    SyncPolicy,
    UploadPolicy,
    DownloadPolicy,
    DeletePolicy,
    ExtractPolicy,
    RecyclePolicy,
    BWList,
    WhiteList,
    UploadStrategy,
    DownloadStrategy,
    UploadMode,
    Lifecycle
)

# Full policy configuration
policy = SyncPolicy(
    upload_policy=UploadPolicy(
        auto_upload=True,  # Auto-upload on session end
        upload_strategy=UploadStrategy.UPLOAD_BEFORE_RESOURCE_RELEASE,
        upload_mode=UploadMode.FILE  # or UploadMode.ARCHIVE
    ),
    download_policy=DownloadPolicy(
        auto_download=True,  # Auto-download on session start
        download_strategy=DownloadStrategy.DOWNLOAD_ASYNC
    ),
    delete_policy=DeletePolicy(
        sync_local_file=True  # Sync deletions to context
    ),
    extract_policy=ExtractPolicy(
        extract=True,  # Extract archives after download
        delete_src_file=True,  # Delete archive after extraction
        extract_current_folder=False
    ),
    recycle_policy=RecyclePolicy(
        lifecycle=Lifecycle.LIFECYCLE_30DAYS,
        paths=[""]  # Apply to all paths
    ),
    bw_list=BWList(
        white_lists=[
            WhiteList(path="/important", exclude_paths=["/important/temp"])
        ]
    )
)

upload_file() and download_file() Methods

These methods use pre-signed URLs for direct file transfer:

Upload (Local -> Session Container):

# Upload a local file to the session's mounted context path
result = session.filesystem.upload_file(
    local_path="/local/path/file.txt",
    remote_path="/workspace/file.txt",  # Must be within context mount
    content_type="text/plain",
    wait=True,  # Wait for sync to complete
    wait_timeout=30.0,
    poll_interval=1.5
)

if result.success:
    print(f"Uploaded {result.bytes_sent} bytes")
    print(f"ETag: {result.etag}")

Download (Session Container -> Local):

result = session.filesystem.download_file(
    remote_path="/workspace/results/output.txt",
    local_path="/local/downloads/output.txt",
    overwrite=True,
    wait=True,
    wait_timeout=300.0
)

if result.success:
    print(f"Downloaded {result.bytes_received} bytes")

Under the hood:

Upload Flow:
1. Get pre-signed upload URL from context service
2. HTTP PUT file to OSS via pre-signed URL
3. Trigger session.context.sync(mode="download") to sync OSS -> container
4. Poll session.context.info() until task completes

Download Flow:
1. Trigger session.context.sync(mode="upload") to sync container -> OSS
2. Poll until sync completes
3. Get pre-signed download URL from context service
4. HTTP GET file from OSS via pre-signed URL
5. Save to local path

Limitations

MQTT Message Size Limit (63KB):

The AgentBay SDK communicates with session containers via MQTT. Messages are limited to 63KB.

For write_file(), the SDK automatically chunks large content:

# From filesystem.py
MQTT_SIZE_LIMIT = 63 * 1024  # 63KB = 64512 bytes
MAX_CONTENT_BYTES = 51 * 1024  # 51KB safe limit after JSON overhead

# Large files are automatically chunked
session.filesystem.write_file("/tmp/large.txt", large_content)
# Internally splits into 51KB chunks, writes first chunk with "overwrite",
# subsequent chunks with "append"

For files larger than a few MB, use upload_file() instead of write_file().

Other Limitations:

  • Context names must be unique within your account
  • Wildcard patterns not supported in RecyclePolicy.paths
  • Maximum concurrent sessions depends on your plan (basic: 10)

4. Session Lifecycle

All Session States

from agentbay.enums import SessionStatus

SessionStatus.RUNNING   # Session is active and usable

How to Create, Pause, Resume, Delete Sessions

Create:

from agentbay import AgentBay
from agentbay.session_params import CreateSessionParams

agent_bay = AgentBay(api_key="your_key")

# Basic creation
result = agent_bay.create()
session = result.session

# With parameters
params = CreateSessionParams(
    image_id="linux_latest",
    labels={"project": "my-project", "env": "dev"}
)
result = agent_bay.create(params)

Pause (Beta):

# Pause and wait for PAUSED state
pause_result = agent_bay.beta_pause(session, timeout=600, poll_interval=2.0)
# Or: pause_result = session.beta_pause(timeout=600)

if pause_result.success:
    print(f"Session paused. Status: {pause_result.status}")

# Fire-and-forget pause (don't wait)
pause_result = agent_bay.beta_pause_async(session)
# Or: pause_result = session.beta_pause_async()

Resume (Beta):

# Resume and wait for RUNNING state
resume_result = agent_bay.beta_resume(session, timeout=600, poll_interval=2.0)
# Or: resume_result = session.beta_resume(timeout=600)

if resume_result.success:
    print(f"Session resumed. Status: {resume_result.status}")

# Fire-and-forget resume
resume_result = agent_bay.beta_resume_async(session)

Delete:

# Delete without syncing context
delete_result = agent_bay.delete(session)

# Delete with context sync (uploads changes first)
delete_result = agent_bay.delete(session, sync_context=True)

# Or via session object
delete_result = session.delete(sync_context=True)

Get Session Status:

status_result = session.get_status()
print(f"Status: {status_result.status}")  # RUNNING, PAUSED, etc.

Timeout and Auto-Cleanup

Sessions have idle timeouts configured by AgentBay. If a session is idle for too long, it may be automatically cleaned up.

To prevent this:
- Keep sessions active with periodic commands
- Use pause/resume for long-running workflows
- Delete sessions explicitly when done

Billing Implications of Each State

State Compute Billing Storage Billing
RUNNING Yes (per-second) Yes
PAUSING Yes (transitioning) Yes
PAUSED No Yes (reduced)
RESUMING Yes (transitioning) Yes
DELETING No No
DELETED No No

Key insight: Pausing sessions stops compute billing while preserving state.

5. Complete Working Example

Here's a full example showing the complete workflow:

from agentbay import AgentBay
from agentbay.session_params import CreateSessionParams
from agentbay.context_sync import (
    ContextSync,
    SyncPolicy,
    UploadPolicy,
    DownloadPolicy,
    RecyclePolicy,
    Lifecycle
)
import os

def main():
    # Initialize client
    api_key = os.getenv("AGENTBAY_API_KEY")
    agent_bay = AgentBay(api_key=api_key)

    session = None
    context = None

    try:
        # ============================================
        # Step 1: Create or get a persistent context
        # ============================================
        print("Creating context...")
        ctx_result = agent_bay.context.get(name="my-project-workspace", create=True)
        if not ctx_result.success:
            raise Exception(f"Failed to create context: {ctx_result.error_message}")

        context = ctx_result.context
        print(f"Context ID: {context.id}")
        print(f"Context Name: {context.name}")

        # ============================================
        # Step 2: Create session with context mounted
        # ============================================
        print("\nCreating session with context mount...")

        # Configure sync policy
        sync_policy = SyncPolicy(
            upload_policy=UploadPolicy(auto_upload=True),
            download_policy=DownloadPolicy(auto_download=True),
            recycle_policy=RecyclePolicy(lifecycle=Lifecycle.LIFECYCLE_30DAYS)
        )

        # Create context sync configuration
        context_sync = ContextSync(
            context_id=context.id,
            path="/workspace",
            policy=sync_policy
        )

        # Create session parameters
        params = CreateSessionParams(
            image_id="linux_latest",
            context_syncs=[context_sync],
            labels={"project": "demo", "purpose": "file-sync-example"}
        )

        # Create the session
        session_result = agent_bay.create(params)
        if not session_result.success:
            raise Exception(f"Failed to create session: {session_result.error_message}")

        session = session_result.session
        print(f"Session ID: {session.session_id}")

        # ============================================
        # Step 3: Upload files to the session
        # ============================================
        print("\nUploading files...")

        # Create a local test file
        local_file = "/tmp/test_upload.txt"
        with open(local_file, "w") as f:
            f.write("Hello from local machine!\nThis file will be uploaded to the cloud.")

        # Upload using pre-signed URL method
        upload_result = session.filesystem.upload_file(
            local_path=local_file,
            remote_path="/workspace/uploaded_file.txt",
            wait=True,
            wait_timeout=60.0
        )

        if upload_result.success:
            print(f"Upload successful! Bytes sent: {upload_result.bytes_sent}")
        else:
            print(f"Upload failed: {upload_result.error_message}")

        # Alternative: Write content directly (for small files)
        session.filesystem.write_file(
            "/workspace/direct_write.txt",
            "This content was written directly via MQTT."
        )

        # ============================================
        # Step 4: Do work in the session
        # ============================================
        print("\nExecuting commands in session...")

        # List files in workspace
        cmd_result = session.command.execute_command("ls -la /workspace")
        print(f"Workspace contents:\n{cmd_result.output}")

        # Create some output files
        session.command.execute_command(
            "echo 'Processing complete at $(date)' > /workspace/results.txt"
        )

        # Read a file
        content_result = session.filesystem.read_file("/workspace/results.txt")
        print(f"Results content: {content_result.content}")

        # ============================================
        # Step 5: Download results
        # ============================================
        print("\nDownloading results...")

        local_download_path = "/tmp/downloaded_results.txt"
        download_result = session.filesystem.download_file(
            remote_path="/workspace/results.txt",
            local_path=local_download_path,
            wait=True,
            wait_timeout=60.0
        )

        if download_result.success:
            print(f"Download successful! Bytes received: {download_result.bytes_received}")
            with open(local_download_path, "r") as f:
                print(f"Downloaded content: {f.read()}")
        else:
            print(f"Download failed: {download_result.error_message}")

        # ============================================
        # Step 6: Check context sync status
        # ============================================
        print("\nChecking context sync status...")
        info_result = session.context.info()
        for status in info_result.context_status_data:
            print(f"  Context: {status.context_id}")
            print(f"  Path: {status.path}")
            print(f"  Status: {status.status}")
            print(f"  Task Type: {status.task_type}")

        # ============================================
        # Step 7: Cleanup
        # ============================================
        print("\nCleaning up...")

        # Delete session with context sync (uploads any remaining changes)
        delete_result = agent_bay.delete(session, sync_context=True)
        if delete_result.success:
            print("Session deleted successfully")
        else:
            print(f"Session deletion failed: {delete_result.error_message}")

        session = None  # Mark as deleted

        # List files in context (they persist after session deletion)
        print("\nFiles in context after session deletion:")
        files_result = agent_bay.context.list_files(context.id, "/")
        for entry in files_result.entries:
            print(f"  {entry.file_name} ({entry.size} bytes)")

        # Optionally delete the context
        # agent_bay.context.delete(context)

    except Exception as e:
        print(f"Error: {e}")

    finally:
        # Ensure session is cleaned up
        if session is not None:
            print("\nCleaning up session in finally block...")
            agent_bay.delete(session)


if __name__ == "__main__":
    main()
